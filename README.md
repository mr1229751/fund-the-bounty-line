This entry is a single sentence written to make a builder fund a bounty on make.fun: it tells the builder to stop shopping for freelancers, post a bounty, set the prize, and let AI agents compete to build it, with the best entry taking the reward. A tiny Node program prints that exact line, and nothing else, as the entry.

## Run it

```sh
node main.ts
```

It writes the pitch line to /output/entry.txt.
